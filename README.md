
# Meu Portfólio
> Um site pessoal criado com HTML, CSS e JavaScript para destacar minhas habilidades e projetos.


## 📌 Sobre o Projeto

Este portfólio foi desenvolvido utilizando HTML, CSS e JavaScript, com o objetivo de apresentar de maneira clara e organizada minhas habilidades, formação e projetos. Os principais conceitos e estruturas trabalhados no código incluem:

- Estrutura semântica em HTML: Utilização de tags semânticas como header, footer, section, e nav para organizar o conteúdo de forma clara e acessível.
- Estilos e layouts responsivos com CSS: Implementação de estilos para tornar o portfólio visualmente atraente e otimizado para diferentes dispositivos, com o uso de media queries e flexbox.
- Interatividade com JavaScript: Adição de funcionalidades dinâmicas como a alternância de temas, manipulação de eventos e navegação interativa.
- Organização e modularização do código: Separação do código em arquivos CSS e JavaScript para manter a estrutura do projeto limpa e facilitar a manutenção.
- Acessibilidade e boas práticas: Garantia de que o portfólio é acessível, com uso de atributos alt em imagens e links de navegação bem definidos.

Este projeto foi desenvolvido para consolidar o aprendizado sobre as tecnologias web e servir como um portfólio profissional para futuras oportunidades.

---
## 🛠️ Tecnologias Utilizadas

- HTML5 – Estruturação semântica da página
- CSS3 – Estilização e layout responsivo
- JavaScript – Funcionalidades interativas como alternância de tema
- Google Fonts – Importação de fontes personalizadas

## 🚀 Como Executar

1. **Clone o repositório**:
   ```bash
   git clone https://github.com/EleandersonRosadeMorais/eleandersonrosademorais.github.io.git
   ```
2. **Abra o projeto no Visual Studio Code ou use o Código abaixo**
   ```bash
   cd Meuportifolio
   code .
   ```
3. **execute o arquivo**`index.html`
   ```bash
   start index.html
   ```
4. **(Opcional) Abrir a página pelo GitHub Page**
   ```bash
   explorer.exe https://eleandersonrosademorais.github.io/
   ```
